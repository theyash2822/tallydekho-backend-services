# TallyDekho — Pairing with Tally Prime

## What is Pairing?
Pairing connects your TallyDekho mobile/web app to Tally Prime running on your Windows computer via the TallyDekho Desktop Agent.

## Step-by-Step Pairing

### Step 1: Install Desktop Agent
- Download the TallyDekho Desktop Agent installer from the TallyDekho website
- Install and run it on the Windows PC where Tally Prime is running
- The Desktop Agent runs in the system tray (bottom-right of Windows taskbar)

### Step 2: Get the Pairing Code
- Open the Desktop Agent
- A 6-digit pairing code is displayed on the screen
- This code is permanent until you unpair — you do not need to regenerate it each time

### Step 3: Enter Code in App
- Open TallyDekho mobile app
- Go to Settings → Tally Prime Sync
- Tap "Enter Pairing Code"
- Type the 6-digit code shown on Desktop Agent
- Tap Confirm

### Step 4: Verify Connection
- After pairing, the app shows "Connected" status
- Tally data begins syncing automatically
- First sync may take a few minutes depending on data size

## Pairing Rules
- Both devices must be on the same WiFi network (LAN)
- Tally Prime must be open and running during pairing
- The Desktop Agent must be running in the background
- One device can be paired per account at a time

## Unpairing
- Go to Settings → Tally Prime Sync → Unpair
- Unpairing generates a new pairing code on the Desktop Agent
- You can re-pair using the new code

## After Pairing
- Dashboard shows real Tally data
- All sales, purchases, vouchers, ledgers, stocks auto-sync
- Sync happens automatically whenever Tally Desktop Agent is running
