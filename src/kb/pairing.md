# TallyDekho — Pairing with Tally Prime

## What is Pairing?
Pairing connects your TallyDekho mobile app to Tally Prime running on your Windows computer via the TallyDekho Desktop App.

## Exact Pairing Steps

### Step 1: Install TallyDekho Mobile App
- Download and install TallyDekho on your Android or iOS phone
- Login with your registered mobile number and OTP

### Step 2: Download TallyDekho Desktop App
- Download the TallyDekho Desktop App installer
- Install it on the **same Windows PC where Tally Prime is installed**
- Both Tally and TallyDekho Desktop must be on the same machine

### Step 3: Open Tally Prime and Select Company
- Open Tally Prime on your Windows PC
- Select the company you want to sync with TallyDekho

### Step 4: Configure Auto Sync in Desktop App
- Open the TallyDekho Desktop App
- It will detect Tally Prime automatically
- Select your company from the dropdown
- Enable "Auto Sync" option

### Step 5: Start the Sync Process
- Click "Start Sync" in the TallyDekho Desktop App
- The Desktop App begins reading your Tally data
- A **6-digit pairing code** is displayed on the Desktop App screen

### Step 6: Enter Pairing Code in Mobile App
- Open TallyDekho mobile app
- Go to Settings → Tally Prime Sync → "Enter Pairing Code"
- Type the 6-digit code shown on the Desktop App
- Tap Confirm / Connect

### Step 7: Data Appears on Mobile
- After successful pairing, your Tally data starts syncing to the mobile app
- Dashboard, Sales, Purchase, Ledgers, Stocks all show real Tally data
- First sync may take 1-5 minutes depending on data size

## Important Notes
- Desktop App and Tally Prime must be on the SAME Windows PC
- Mobile and PC must be on the SAME WiFi network
- Tally Prime must be open during pairing
- Auto Sync keeps data updated automatically after pairing

## Pairing Code
- The 6-digit code is shown in the Desktop App after sync starts
- It is permanent and does not change unless you unpair
- If you reinstall or unpair, a new code is generated

## After Pairing
- Dashboard shows real revenue, outstanding, stock data
- All vouchers, ledgers, stocks auto-sync from Tally
- Auto sync runs whenever Tally is open and Desktop App is running

## Troubleshooting Pairing
- Code not showing? → Make sure you clicked "Start Sync" in Desktop App
- Code entered but not connecting? → Check both devices are on same WiFi
- Data not appearing after pairing? → Wait 2-3 minutes for first sync to complete
- Desktop App not detecting Tally? → Make sure Tally Prime is open first
