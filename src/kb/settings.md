# TallyDekho — Settings

## Profile Settings
- Name: update your display name
- Phone: your registered mobile (read-only — used for login OTP)
- Email: add email for communication (optional)
- Access: Settings → Profile

## Security / 2FA
- Enable PIN: set a 4-digit PIN for app lock
- Biometric: enable Face ID / Touch ID / Fingerprint
- PIN is required on app open (can be bypassed with biometrics)
- To change PIN: Settings → Security → Change PIN
- To disable: Settings → Security → Remove PIN

## Company Information
- Shows company name, GSTIN, address, state from Tally
- Read-only — update in Tally Prime and resync
- Company logo: upload here → appears on all PDFs

## Tally Prime Sync
- Shows connection status: Connected / Not Paired
- Last sync timestamp
- Sync Now: trigger manual sync
- Enter Pairing Code: to pair with a new Desktop Agent
- Unpair: disconnect from current Desktop Agent

## Notification Settings
- WhatsApp Notifications: enable/disable for payment reminders, alerts
- Email Notifications: for compliance reminders
- Low Stock Alerts: notify when stock falls below reorder level
- Compliance Reminders: GST filing due dates

## Language & Format
- Language: choose from English, Hindi, Gujarati, Marathi, Tamil, Telugu, Kannada, Punjabi, Bengali, Malayalam, Odia
- Currency Format: Indian (₹, L, Cr) or International (K, M, B)
- Date Format: DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD
- Settings sync across devices via backend

## Voucher Configuration
- Invoice Format: Format 1, 2, or 3 (different layouts)
- QR Code: enable and upload QR image for invoices
- Terms & Conditions: add custom T&C text to invoices
