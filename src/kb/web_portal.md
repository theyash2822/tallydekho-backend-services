# TallyDekho — Web Portal

## What is the Web Portal?
The TallyDekho Web Portal is the desktop browser version of TallyDekho.
Access it from any browser — Chrome, Firefox, Safari, Edge.
Same data as the mobile app — both sync from the same backend.

## Accessing the Web Portal
- Open your browser and go to the TallyDekho web URL
- Login with your registered mobile number + OTP
- Same login as the mobile app

## Available Modules
- Dashboard: KPI overview with charts
- Sales: Sales register, create invoices, orders
- Purchase: Purchase register, create purchase vouchers
- Inventory: Full stock management with filters
- Expenses: Expense tracking
- Payments: Cash & Bank, Receivables, Payables, Loans
- Reports: P&L, Balance Sheet, Trial Balance, GST, E-Way Bill, E-Invoice, Other Taxes, Audit Trail
- AI Insights: Business analytics and recommendations
- Settings: Profile, Company, Notifications, Voucher Config

## Key Differences from Mobile
- Larger screen — tables and charts show more data
- Keyboard shortcuts for faster data entry
- Better for printing and PDF generation
- Same real-time data — changes reflect immediately

## Company Logo
- Upload from Settings → Company Information → Upload Logo
- Logo appears on all generated PDFs/invoices

## Voucher Configuration
- Settings → Voucher Config
- Choose invoice format (Format 1, 2, or 3)
- Enable/disable QR code, Terms & Conditions
- Upload QR code image

## Reports in Web Portal
- All reports support date range filtering
- Export to PDF or print directly from browser

## Common Questions
Q: Web portal shows different data than mobile?
A: Both use the same backend. If data differs, refresh both and trigger a Tally sync.

Q: Can I create invoices on the web portal?
A: Yes — same functionality as mobile for creating vouchers.

Q: Web portal is slow to load?
A: Clear browser cache. Try a different browser. Check your internet connection.
