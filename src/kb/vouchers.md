# TallyDekho — Vouchers & Entries

## Voucher Types Available
- Sales Invoice
- Purchase Invoice
- Credit Note (Sales Return)
- Debit Note (Purchase Return)
- Payment Voucher
- Receipt Voucher
- Journal Entry
- Contra Entry
- Sales Order
- Purchase Order
- Delivery Note

## Creating a Sales Invoice
1. Tap Sales tab → tap the + (plus) button
2. Select party name (customer) from dropdown or type to search
3. Add items: tap "Add Item" → search stock item → enter quantity and rate
4. Add GST if applicable (auto-calculated from item master)
5. Add other charges if needed
6. Tap "Save" — voucher is created and synced to Tally

## Creating a Purchase Invoice
1. Tap Purchase tab → tap + button
2. Select supplier/vendor from party list
3. Add items with quantity and rate
4. Save — syncs to Tally automatically

## Payment & Receipt Vouchers
- Payment: Money going OUT (paying a vendor, expense)
- Receipt: Money coming IN (receiving from a customer)
- Go to Vouchers tab → select type → fill party, ledger, amount, date

## Credit Note / Debit Note
- Credit Note: Customer returns goods — reduces their outstanding
- Debit Note: You return goods to vendor — reduces your payable
- Available under Sales and Purchase tabs respectively

## Searching Vouchers
- Use the search icon on any register (Sales/Purchase/Voucher list)
- Search by: voucher number, party name, amount
- Example: type "101" to find voucher #101

## Optional Entries (Draft Mode)
- Optional entries are saved in TallyDekho but NOT posted to Tally books
- They appear with a purple "Draft" badge
- To post to Tally: open the voucher → tap "Post to Tally"
- Useful for pre-approval workflows

## Editing / Deleting Vouchers
- Vouchers synced from Tally are read-only in TallyDekho (edit in Tally directly)
- Vouchers created in TallyDekho can be edited before posting

## Daybook
- Shows all vouchers across all types for a selected date range
- Access via Reports → Daybook
- Supports multi-select for bulk operations
